# 💍 Свадебный сайт

Готовый одностраничный сайт для свадьбы. Работает на телефоне, планшете, ПК. Не требует сервера, базы данных, программирования.

## 🎯 Что внутри

- **Главный экран** — имена пары, дата свадьбы, плавная анимация
- **Обратный отсчёт** — живой таймер до дня свадьбы
- **Наша история** — текст + 3 фото-заглушки
- **Место проведения** — адрес и кнопка «Открыть на карте»
- **Программа дня** — таймлайн с событиями
- **RSVP-форма** — гости подтверждают присутствие
- **Фоновая музыка** — включается кнопкой в углу
- **Адаптивный дизайн** — работает на всех экранах

## 🛠️ Технологии

- HTML5
- CSS3 (анимации, градиенты, адаптив)
- JavaScript (таймер, музыка, форма)
- Google Fonts

Без зависимостей, фреймворков, сборки. Один файл `index.html`.

## 🚀 Как запустить

1. Скачай `index.html`
2. Открой в браузере
3. Всё работает

## ✏️ Как изменить контент

### Изменить имена

Найди строку:

```html
<h1 class="hero-names">
  Александр
  <span class="amp">&</span>
  Мария
</h1>
Замени Александр и Мария на свои имена.

Изменить дату
Найди:

html
<div class="hero-date">15 · 06 · 2027</div>
Замени на свою дату.

Также поменяй дату в JavaScript:

javascript
const weddingDate = new Date('2027-06-15T15:00:00').getTime();
Изменить место
Найди:

html
<div class="place-name">Усадьба «Тихие Пруды»</div>
<div class="place-address">Московская область, Одинцовский район</div>
Замени на своё место. Ссылку на карту поменяй тут:

html
<a href="https://maps.google.com" target="_blank" class="place-btn">Открыть на карте</a>
Изменить программу дня
Найди блоки:

html
<div class="timeline-item">
  <div class="timeline-content">
    <div class="timeline-time">14:00</div>
    <div class="timeline-title">Сбор гостей</div>
  </div>
  <div class="timeline-dot"></div>
</div>
Меняй время и события. Можно добавлять или удалять блоки.

Добавить свои фото
Положи фото в ту же папку, что index.html

Назови photo1.jpg, photo2.jpg, photo3.jpg

В HTML замени:

Было:

html
<div class="story-photo">📸</div>
Стало:

html
<div class="story-photo" style="background-image: url('photo1.jpg'); background-size: cover; background-position: center;"></div>
Изменить музыку
Найди:

html
<audio id="bgMusic" loop>
  <source src="https://cdn.pixabay.com/audio/2022/05/27/audio_1808fbf07a.mp3" type="audio/mpeg">
</audio>
Замени ссылку на свою. Можно положить MP3 в папку и написать src="music.mp3".

🎨 Как изменить цвета
Основные цвета в коде:

#c9a882 — золотой (акцент)

#4a3728 — тёмно-коричневый (заголовки)

#faf7f2 — кремовый (фон)

#f5ebe0 — бежевый (секции)

#8b7355 — коричневый (текст)

Замени через Ctrl+H в редакторе.
